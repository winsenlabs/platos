# @platos/adapter-redis-cache

Implements TWO owner-supplied ports — one namespaced keyspace behind one Redis client:

- the memory `Cache` port
- the jobs `IdempotencyStore` port

ADR M0.3 §15 amendment: one vendor client is one adapter DIRECTORY, and a
directory may satisfy more than one port when the ports sit behind the same
client. §4's body already spells this directory "per-context repositories,
owner-tagged"; ownership is carried by the owner tag and enforced by
`CANONICAL_STORE_ADAPTERS`, not by the package boundary. It is still the sole
holder of its vendor client, only `apps/core-api` may import it
(`adapters-only-from-core`), and it may import no other adapter
(`adapter-is-self-contained`).

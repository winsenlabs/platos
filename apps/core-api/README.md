# @platos/core-api

ADR M0.3 §4: THE single V1 deployable. It is the composition root — the ONLY
place that may import `packages/adapters/*` — and it hosts every transport.
Transports are thin: they call context use-cases and hold no business rule.

This project's SOURCE tree is adopted (WIN-297): `src/` is hand-written, and
`scripts/arch/composition-root.mjs` narrows `adapters-only-from-core` further,
to the one composition module inside it. Its `package.json`, `tsconfig.json` and
this README stay generated by `scripts/arch/gen-v1-skeleton.mjs`.

Run it with `pnpm --filter @platos/core-api start` after `pnpm build:v1`.

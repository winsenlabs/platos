Five-minute agent

Platos is where you build an agent, and where you find out why it did what it did. This page gets you from an empty environment to a working agent that answers a real message.

1 · Add a model key

Go to Providers and add one BYOK credential. Platos verifies it immediately with a live call — a key that lists as “ok” has actually worked, not just parsed.

2 · Create the agent

Three fields: a name, a model, a prompt. Everything else — tools, memory, budgets — has a working default and can wait until the agent needs it.

3 · Say something

Open the playground. The right pane shows the exact assembly the model receives: every prompt block, tool schema, and recalled memory, with token counts. Inspection is not a debug mode — it is the default view.

4 · Give it hands

Connect an entity — a wire service that dials in, or an MCP server Platos dials out to. Discovered tools appear in the registry with live dispatchability, and you expose them to agents explicitly.

## Canonical REST prefix

- **Prefix:** `/api/v1`
- **Rule:** A version is a property of the contract, not the code path. The REST major axis is the URL segment, pinned by Nest @Version — never a per-controller literal string.
- **Expression:** `setGlobalPrefix("api") + enableVersioning({ type: URI, defaultVersion: "1" }) + @Version("1")`
- **Build-id header:** `X-Platos-Contract-Version` · **floor request:** `X-Platos-Contract-Min`
- **Literal migration (M4 pre-gate):** 18 `@Controller("api/v1/...") hardcoded literals` → `setGlobalPrefix + enableVersioning + @Version("1")` — status **pending**. no-bare-prefix lint: generation fails on any literal "api/v1" string once the migration lands, so the drift-check reads structure, not a string (ADR M0.4 §2 REST row, §5 item 2).

## Accepted decisions (D0–D7)

| # | Decision | Status | Correction |
|---|---|---|---|
| D0 | Screen reconciliation | **RESOLVED** | The design directory holds 47 HTML pages: 46 numbered (files 06 and 33 do not exist) plus PlatosNav. 43 carry mapped demand. The 4 existing-but-undemanded pages are exactly 00-index, 43-docs, 47-parts, and PlatosNav (index, docs viewer, component parts, and the nav shell — structural, not feature screens). Each gets mapped demand or an explicit no-backend-contract exclusion before M4 exit. |
| D1 | REST version lives in URL major + additive build-id header | **accepted** | URL pins the major; a contract header carries the additive build id. Migrate the 18 literal @Controller("api/v1/...") controllers to @Version("1") FIRST, before the drift-check can enforce anything. |
| D2 | MCP contract version separate from protocol negotiation | **accepted** | The MCP protocol date stays spec-negotiated; the Platos semver rides in serverInfo.version + _meta. Collapse the three hardcoded "0.1.0" into one const first. |
| D3 | Durable-token lifetime | **CORRECTED** | Durable tokens survive until terminal state plus their retention window — NOT literally forever. A token is honored while its run can still reach a terminal state and through its defined retention. |
| D4 | Absent stream version baseline | **CORRECTED** | A missing stream version maps to V1 only at identified legacy ingress points, not as a blanket default everywhere. New surfaces must carry an explicit sv/pv. |
| D5 | Introducing the canonical envelope over live bare-object routes | **CORRECTED** | Compatibility adapters preserve the legacy response shape and must not emit an ambiguous dual response shape. Existing routes keep their exact current shape during the window; new contexts are envelope-native. No route ever returns two shapes ambiguously. |
| D6 | Self-host the OpenAPI UI | **accepted** | Vendor swagger-ui-dist locally rather than loading it from a CDN, so the contract document does not depend on a third party. |
| D7 | Field-level compatibility enforcement | **accepted** | Mandate DTO schema declaration on all new v1 contexts plus the retrofitted envelope, so the breaking-change guard can enforce additive-only field compatibility. |

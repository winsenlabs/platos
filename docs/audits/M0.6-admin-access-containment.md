## Host-side acceptance — OPERATOR BOUNDARY (repo cannot perform)

Every clause below requires an authenticated SSH session to `$PLATOS_EDGE_HOST`.
The repository has no such access and must not fabricate it. **Critical
sequencing:** root and `ubuntu` currently authenticate with the *same* key
fingerprint `SHA256:LG+wHPjN/7tSv1sC3bHNArMJpFVSUJDU8d0hRiiXGqQ`, so there is **no
independent recovery path today** — the recovery key must be installed and proven
from a fresh session **before** any restriction, or the operator risks lockout.

Precise operator runbook (fingerprints/setting-names only; never paste key
material):

1. **Provision an independent recovery key FIRST.** On a secured workstation:
   `ssh-keygen -t ed25519 -C "platos-recovery-$(date +%Y%m%d)" -f ~/.ssh/platos_recovery`.
   Append only the `.pub` to `ubuntu`'s `authorized_keys` through the existing
   session. Prove from a **fresh** terminal: `ssh -i ~/.ssh/platos_recovery
   ubuntu@$PLATOS_EDGE_HOST 'sudo -n whoami'` must print `root`. Keep this session
   open during every step below.
2. **Attribute the root keys before pruning** (fingerprints only):
   `sudo ssh-keygen -lf /root/.ssh/authorized_keys` and compare to
   `SHA256:LG+wHPjN/7tSv1sC3bHNArMJpFVSUJDU8d0hRiiXGqQ` (tejas@fandesk.ai) and
   `SHA256:YJBGBMMmlNsQ0z66C7sn81mDkHZEVdlaJS7EUCrsBXg` (tejas@winsen.ai). Confirm
   the winsen key is current/controlled before removing any unattributed line.
3. **Re-verify key-only auth in force:** `sudo sshd -T | grep -E
   'passwordauthentication|kbdinteractiveauthentication|pubkeyauthentication|permitrootlogin'`
   must show password `no`, keyboard-interactive `no`, pubkey `yes`.
4. **Source-restrict SSH** (highest lockout risk — only with the recovery session
   open): Tailscale (`tailscale up`, permit `:22` from `100.64.0.0/10` + admin
   allowlist) or `ufw` (`allow 80,443/tcp`; `allow from <ADMIN_CIDR> to any port 22
   proto tcp`; then `enable`). Verify before ending the session.
5. **Migrate off root:** set `PermitRootLogin no` (currently `prohibit-password`),
   `sudo sshd -t && sudo systemctl reload ssh`, re-prove the `ubuntu` path.
6. **Redeploy compose** so `:3030` is loopback on the host; `ss -ltnp | grep 3030`
   shows `127.0.0.1`.
7. **Re-record redacted before/after** from an off-host machine (`nmap -Pn
   -p22,80,443,3030 $PLATOS_EDGE_HOST`): `:3030` closed/filtered, `:22` reachable
   only from the allowlisted source.

Until steps 1–7 are performed and verified live, the host-side clauses remain
open and WIN-291 must **not** be marked Done.
